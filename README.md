# Sindhu S — Unique Portfolio

The missing `style.css` and `script.js` files have been restored. The portfolio is now responsive and includes the intended interactions.

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive visual styling
- `script.js` — cursor interaction and certificate modal
- `assets/certificates/` — certificate image folder

## Run locally
1. Extract the folder.
2. Open `index.html` in Chrome or Edge.
3. The page works directly without installation.

## Important
The original ZIP supplied for this repair contained only `index.html` and `README.md`. The certificate image files were not included, so the portfolio shows a clear placeholder when those files are missing. Add your original certificate images to `assets/certificates/` using the filenames already referenced in `index.html`.

The profile image is loaded from the public GitHub URL already present in `index.html`.
